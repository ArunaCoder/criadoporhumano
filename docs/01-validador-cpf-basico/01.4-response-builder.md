## 1.4 Response Builder

### Passo 10: Struct HttpResponse

#### Checklist

- [ ] Em `response.rs`: criar struct:
  ```rust
  pub struct HttpResponse {
      status_code: u16,
      status_text: &'static str,
      content_type: &'static str,
      body: String,
  }
  ```
- [ ] Implementar `new()` com defaults (200 OK, application/json)

### Passo 11: Método to_bytes()

#### Checklist

- [ ] Implementar método que gera String no formato HTTP:
  ```rust
  pub fn to_bytes(&self) -> Vec<u8> {
      format!(
          "HTTP/1.1 {} {}\r\nContent-Type: {}\r\nContent-Length: {}\r\n\r\n{}",
          self.status_code, self.status_text, self.content_type,
          self.body.len(), self.body
      ).into_bytes()
  }
  ```
- [ ] Testar compilação: `cargo check`

### Passo 12: Helpers para Status Codes

#### Checklist

- [ ] Criar métodos: `ok(body: String)`, `bad_request()`, `not_found()`, `server_error()`
- [ ] Exemplo:
  ```rust
  pub fn not_found() -> Self {
      Self {
          status_code: 404,
          status_text: "Not Found",
          content_type: "application/json",
          body: r#"{"error":"Not Found"}"#.to_string(),
      }
  }
  ```

### Passo 13: Enviar Response

#### Checklist

- [ ] Em `handle_connection`: obter `TcpStream` de volta do `BufReader` (usar `into_inner()`)
- [ ] **CRÍTICO:** Adicionar `Connection: close` em TODAS as respostas:
  ```rust
  // No método to_bytes() do HttpResponse
  format!(
      "HTTP/1.1 {} {}\r\nContent-Type: {}\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{}",
      status_code, status_text, content_type, body.len(), body
  )
  ```
- [ ] Chamar `stream.write_all(&response.to_bytes())?`
- [ ] Chamar `stream.flush()?`
- [ ] **CRÍTICO:** Adicionar `stream.shutdown(std::net::Shutdown::Both)?` após flush
- [ ] Testar: `curl http://localhost:8080` deve receber resposta HTTP válida
- [ ] Validar: `curl -v http://localhost:8080` deve mostrar "Connection: close" no header
- [ ] Garantir que a resposta NÃO tenha mensagem de erro específica de path traversal ou invalid path, para não servir de subsídio para atacante saber estrutura do servidor.
